# Abdul Aziz Abdulai — Personal Website

A long-term personal platform combining portfolio, academic hub, blog, resource library, media portfolio, and private productivity dashboard.

**Owner:** Abdul Aziz Abdulai
**Status:** In active development (see ROADMAP.md)

## Tech Stack
- Frontend: Next.js, React, TypeScript, Tailwind CSS, Framer Motion
- Backend: FastAPI, Python, SQLAlchemy, Alembic
- Database: PostgreSQL (Supabase)
- Hosting: Vercel (frontend), Render (backend), Supabase (database)
